AVOIDING CAR

An autonomous robotic vehicle built using Arduino UNO, Ultrasonic Sensor and Servo Motor for intelligent obstacle detection.

VIEW SOURCE CODE PROJECT IMAGES

ABOUT PROJECT

The Arduino based Obstacle Avoiding Car is an autonomous robot that detects obstacles using an ultrasonic sensor and automatically changes its direction to avoid collisions.

HARDWARE COMPONENTS

Arduino UNO

Main controller of the robot.

HC-SR04

Ultrasonic sensor for obstacle detection.

Servo Motor

Rotates sensor for scanning.

L298N Driver

Controls DC motors.

DC Motors

Provides robot movement.
